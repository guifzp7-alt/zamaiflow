# ZAMAI FLOW — Landing page

Projeto separado do sistema principal. Inclui Header, Hero, Problemas, Como funciona, Recursos, prévia estática do painel, Instagram/TikTok, FAQ, CTA e Footer, em HTML e CSS responsivos. O tema claro abre por padrão; o botão de lua/sol no cabeçalho alterna para o tema escuro e salva a preferência neste navegador.

## Prévia local

Abra `index.html` no navegador ou sirva a pasta com qualquer servidor estático. Não há dependências de backend nesta etapa. O FAQ usa elementos nativos expansíveis; a navegação leva às seções da página.

Login, pagamentos, formulários de cadastro e banco de dados ainda não estão conectados. A integração TikTok está identificada como “Em breve”; preços e planos não foram definidos.
